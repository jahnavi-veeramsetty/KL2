Setting Up VS Code for Python (Recommended)

Setting up VS Code

1
Download VS Code: Go to code.visualstudio.com → Download for your OS → Install
2
Install the Python Extension: Open VS Code → Ctrl+Shift+X (Extensions) → Search "Python". Install "Python" by Microsoft.
3
Select your Python Interpreter: Ctrl+Shift+P → "Python: Select Interpreter" → Choose Python 3.11+ (or your venv if already created)

Essential Extensions for Python Development

Python (Microsoft) - autocomplete, linting, debugging
Pylance - advanced type checking and IntelliSense
Black Formatter - auto-format code on save
GitLens - see git blame inline
Python Test Explorer - run pytest tests visually
