Virtual Environments (venv)

Complete venv Workflow – From Creation to Deactivation

Step-by-Step Venv Workflow

Step 1: Navigate to your project folder

bash 
mkdir ~/projects/my-python-app
cd ~/projects/my-python-app

Step 2: Create the virtual environment

bash 
python -m venv venv

Step 3: Activate the virtual environment

bash 
# Windows (Command Prompt):
venv\Scripts\activate

# macOS / Linux:
source venv/bin/activate

After activation, your prompt changes to include (venv). You are now safely inside the isolated environment!

Step 4 & 5: Install packages and Verify

bash 
pip install requests pandas
which python    # Should show venv/bin/python
python --version

Step 6: Deactivate when done

bash 
deactivate

venv Inside VS Code – Automatic Activation

VS Code Integration: After creating a venv, VS Code often prompts: "We noticed a new virtual environment. Do you want to select it?". Click Yes.

Manual selection: Ctrl+Shift+P → "Python: Select Interpreter" → Choose your venv.

Crucial Step: .gitignore

You must exclude the venv folder from Git! Virtual environments are OS-specific, massive, and should be recreated using requirements.txt instead.

bash 
echo "venv/" >> .gitignore
echo "__pycache__/" >> .gitignore
echo "*.pyc" >> .gitignore
echo ".env" >> .gitignore
