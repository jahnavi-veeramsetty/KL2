Installing Python 3.11+: The Foundation of Everything

Installation Guide – All Platforms

Windows

Method 1: Official Installer (recommended for beginners)

1
Go to python.org/downloads
2
Click "Download Python 3.11.x" (the big yellow button)
3
Run the installer
4
CRITICAL: Check "Add Python to PATH" checkbox at the bottom!
5
Click "Install Now"

Verify installation (open Command Prompt or PowerShell):

bash 
python --version         # -> Python 3.11.x
pip --version             # -> pip 23.x from C:\Users\...\python3.11

If python command not found after install: Search "Environment Variables" in Windows → Path → Add Python folder

macOS

Method 1: Official Installer

1
python.org/downloads → Download Python 3.11 for macOS
2
Open the .pkg file and follow instructions

Verify (open Terminal):

bash 
python3 --version        # -> Python 3.11.x
pip3 --version            # -> pip 23.x

Linux (Ubuntu/Debian)

bash 
sudo apt update
sudo apt install python3.11 python3.11-venv python3-pip
python3.11 --version

Common Issue: Multiple Python versions

If "python" shows 2.7 but "python3" shows 3.11, always use python3 and pip3 on Mac/Linux.

pyenv – Managing Multiple Python Versions Like a Pro

pyenv lets you install and switch between multiple Python versions. Perfect when you work on projects requiring different Python versions.

bash 
# Install pyenv (macOS/Linux):
curl https://pyenv.run | bash

# Add to ~/.bashrc or ~/.zshrc:
export PATH="$HOME/.pyenv/bin:$PATH"
eval "$(pyenv init -)"

# Install specific Python versions:
pyenv install 3.11.5

# Set global default:
pyenv global 3.11.5

# Set version for a specific project folder:
cd my-project
pyenv local 3.11.5       # creates .python-version file
python --version          # -> Python 3.11.5 in this folder only!
